# Launch checklist

Items the owner needs to confirm or supply. Nothing here blocks a preview deploy.

## Content
- [ ] WhatsApp number and social media links (Admin → Settings; WhatsApp currently 0814 483 3999)
- [ ] Social media links (Facebook, X, Instagram, LinkedIn) — hidden until set
- [ ] Real listings and photos (sample Nigerian listings are seeded; delete or edit them in `/admin/properties`)
- [ ] Team photos / named valuers with ESVARBON registration numbers (strongest trust signal on valuation sites)
- [ ] Typical turnaround time for a standard valuation, if you want to publish one
- [ ] Bank / lender panels you are on (we only name confirmed panels)
- [ ] Testimonials from real clients, with permission (none are shown until supplied)

## Compliance
- [ ] Auctioneer's licence (Lagos State Auction Law 2015) before promoting Auctioneering
- [ ] FRC registration status before making IFRS 13 / financial-reporting claims
- [ ] Permission to show NIESV / ESVARBON names (logos are not used)

## Accounts and keys (never paste these into chat)
- [ ] Supabase project created (region: West EU / London)
- [ ] `SUPABASE_ACCESS_TOKEN` and `VERCEL_TOKEN` added to the Claude cloud environment
- [ ] Allowed domains: api.vercel.com, vercel.com, api.supabase.com, *.supabase.co
- [ ] Admin email address(es)
- [ ] Optional: Resend account + DNS records for valueconnect.com.ng (email alerts)
- [ ] Domain DNS access at the registrar (A record + CNAME for www)
